## 🚨 Reporting a Vulnerability

If you discover a security issue or vulnerability in any of the open-source labs or automated pipelines:

1. **Do NOT open a public GitHub issue.**
2. Send an email directly to **[sandeep.mothukuris@gmail.com](mailto:sandeep.mothukuris@gmail.com)** with the subject line:
   `[SECURITY VULNERABILITY] <Component Name>`.
3. Include:
   - Description of the vulnerability.
   - Proof of Concept (PoC) or reproduction steps.
   - Potential impact assessment.

Security reports receive prompt triage within 24–48 hours. Responsible disclosure is deeply appreciated.
